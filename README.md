# BregBike — Local Bike Rental Website

BregBike is a single-page prototype website for a Software Engineering group project.
The idea is a local peer-to-peer bike rental platform for Furtwangen, Freiburg, and the Black Forest region.

Users can search for available bikes, filter by location and bike type, select rental dates, choose optional extras, and create a reservation. After selecting a bike, a small browser-based bike mini-game is unlocked as a playful extra feature.

## Features

* Local bike rental concept for Furtwangen and Freiburg
* Search by pickup location, return location, date, and bike type
* 20 fictional bikes with different categories and prices
* Booking summary with optional extras
* Reservation confirmation
* Small canvas-based bike mini-game
* Customer reviews section
* Fully client-side single-page website

## How to Run

Clone the repository and open the HTML file in a browser:

```bash
git clone <repo-url>
cd <repo-folder>
```

Then open:

```bash
index.html
```

No installation or backend server is required.
